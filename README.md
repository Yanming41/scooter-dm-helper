# scooter-dm-helper

一个个人小工具,用来更方便地在小红书上浏览、筛选二手商品(最初是二手电动滑板车,后来扩展到通用二手商品类目)。它会抓取符合条件的笔记、识别商品型号、比对市场价格,并整理成报告,方便个人挑选商品时参考。

其中的私信辅助功能仅用于**起草**回复草稿,所有消息发送前都需要本人手动确认,不存在自动/无人值守发送逻辑。

> A personal tool for browsing and filtering secondhand listings on Xiaohongshu (Little Red Book) more conveniently — originally built for electric scooters, later generalized to other secondhand categories. It crawls matching posts, identifies the product model, cross-checks market pricing, and compiles a report to help with personal purchase decisions.
>
> The private-message helper only **drafts** reply suggestions — every message still requires manual confirmation from the account owner before it is sent. There is no autonomous/unattended sending.
